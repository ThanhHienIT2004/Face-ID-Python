# Face Recognition Project  
This project implements a face recognition system using **OpenCV** and **Python**. It includes functionalities for:  
- **Face Detection**  
- **Training a Face Recognizer**  
- **Recognizing Faces in Real-Time**

## 🌟 Features  
- **Face Detection**: Uses Haar Cascade Classifier to detect faces in real-time.  
- **Face Recognition**: Recognizes faces using the **LBPH (Local Binary Patterns Histograms)** algorithm.  
- **Training**: Allows users to train the recognizer with new faces.  
- **User Interface**: Simple GUI for inputting face IDs and training the model.
